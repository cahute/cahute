AmigaOS specific implementation details
=======================================

This document details implementation details specific to
:ref:`feature-topic-system-amigaos`.

Serial device management
------------------------

In order to handle serial devices, we communicate with the ``serial.device``
device; see the `AmigaOS Serial Device Guide`_ for more information.

.. _AmigaOS Serial Device Guide:
    https://wiki.amigaos.net/wiki/Serial_Device
