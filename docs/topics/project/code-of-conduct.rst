Code of conduct
===============

.. todo::

    While codes of conduct are important and necessary as soon as interactions
    become frequent on any project, all of them require strict enforcement and
    a multi-person governance, which for now we don't have.

    For now, and until more people are involved with the project, the baseline
    is: be decent, and remember the people using or contributing to the project
    are human beings of any gender and sexuality with feelings and emotions,
    who, as long as you both understand and respect that, deserve to use
    and contribute to the project just as you do.
